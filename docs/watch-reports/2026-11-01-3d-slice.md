## 介面:玻璃觀測站(僅此頁)

- 近黑藍灰底;所有面板為浮於世界上的毛玻璃(backdrop blur、半透明深色、1px 高光邊、大圓角)。
- 字型:Inter + Noto Sans TC(Google Fonts;依 google/fonts 的 `ofl/inter/METADATA.pb`、`ofl/notosanstc/METADATA.pb` 皆為 OFL);數字等寬。
- 居民色以發光細節呈現:頭像環、標記;頭像改發光代表色圓圈。
- 動效:面板模糊淡入、時間數字翻動、major 事件時面板邊緣金光繞一圈(CSS conic 漸層);reduced-motion 關閉。
- 即時欄沿用精簡/詳細分級與對話串卡邏輯,深色串卡、氣泡為低飽和居民色底 + 白字(唯讀引用 `store.js`、`names.js`、`views/livefeed.js`,未改其行為)。

## 效能

1400px、預設 GPU 路徑、60 秒:**60.0 fps**;p50/p95/p99 = 16.7/16.8/16.8 ms,最大 17.2 ms,無任何幀超過 25 ms。

## 已知限制 / 未驗證

- 只量了 headless Chrome 的 GPU 路徑;強制軟體繪圖(SwiftShader)只有 3 fps——無 GPU 的機器會很慢,全鎮版需要降級策略。
- 泡泡互相重疊時不會自動錯開。
- 窄螢幕版面只寫了 CSS 規則,未實際截圖。
- 小島外圍直接融入深色霧;放十棟建築時邊界處理需重新設計。

## 我的審查意見(供拍板參考)

- 方向符合規格:圓角疊塊、糖果色、柔和陰影;夜景的窗光與路燈光池最接近 Townscaper 的氣味。
- 白天的光偏平、偏冷白,「晨金」的暖度不足——全鎮版可再加強太陽暖色與天光對比。
- 路燈是細黑桿,和圓潤語言不搭,全鎮版建議改成粗短圓柱。
- 夜景島外大片深藍顯得空;全鎮版地塊變大後會緩解,也可加遠景島或燈火。
